# Module B — CNV-based malignancy confirmation for `GSE178318` epithelial-proxy cells

Written before running (per `modules/README.md`'s working-structure convention), locking the method and reference-population choice so they aren't picked after seeing the result. This is the follow-up to `tgt_ceacam5.md`'s epithelial-proxy screen, per web-ChatGPT's PR #74 round-2 guidance: the epithelial-proxy screen alone does not confirm malignancy; `GSE178318`'s own publication confirms it via InferCNV.

## What this is and is not

This is a **chromosome-arm-level relative expression score**, not a reproduction of the source publication's fine-grained, per-gene-windowed InferCNV. It is a real, methodologically standard simplification (arm-level or chromosome-level aggregate CNV scoring is used in multiple published CNV-inference workflows as a lighter-weight alternative to full gene-window smoothing), not an ad hoc substitute — but it has materially coarser resolution than the paper's own method and will not detect focal (sub-arm) copy-number events. Stated explicitly everywhere this result is used.

## Method (locked before running)

1. **Gene → chromosome-arm mapping**: `DATA/1.Databases/HGNC_gene_id_mapping/raw/hgnc_custom_download.tsv` (already-fetched, local; `Ensembl gene ID` + `Chromosome` columns), joined against `GSE178318_genes.tsv.gz`'s Ensembl IDs. Chromosome-arm parsed via `^(\d{1,2}|X|Y)([pq])` from HGNC's cytogenetic-band string (e.g. `17p13.3` → `17p`); rows that don't match this pattern (withdrawn/reserved HGNC entries, unplaced/centromeric genes, mitochondrial genes) are excluded from arm scoring. Coverage: 25,376 of 33,694 (75.3%) of `GSE178318`'s genes resolve to a chromosome arm. An arm bucket is only used if it has >=10 resolved genes (avoids single-gene-driven noise).
2. **Reference/normal population**: QC-passing cells classified `immune` (per `scripts/annotate_gse178318_cell_types.py`'s existing classification) **within `PRIMARY_CRC`/`LIVER_METASTASIS` samples only** — not `PBMC` samples. `PBMC` cells go through a different collection/processing pipeline (blood draw vs. tissue dissociation) than tumor-site samples; using them as the CNV reference risks a technical batch artifact being read as a CNV signal. Tumor-site immune cells share the same dissociation/library-prep pipeline as the epithelial-proxy cells being scored, which is the more standard and defensible reference choice. Restricted to the same patient cohort as the epithelial-proxy population being scored (see step 6) — a treated-cohort dossier must not be scored against a pooled or treatment-naive reference, since treatment itself can shift the immune transcriptional program.
3. **Per-cell arm signal**: for each cell, per arm, `log1p(arm_raw_count_sum / total_UMI * 10000)` (CP10K-style per-cell library-size normalization, same spirit as the existing marker-score normalization). Reference mean and SD per arm are computed from the reference population defined in (2).
4. **Per-cell CNV score**: for each epithelial-proxy cell (QC-passing, classified `epithelial` in `PRIMARY_CRC`/`LIVER_METASTASIS` samples), per-arm z-score against the reference mean/SD, then an aggregate score = mean of `z^2` across all usable arms (a chi-square-like aggregate, not a simple sum, so the score isn't just proportional to the number of arms).
5. **CNV-high / malignancy-consistent threshold**: computed from the **reference population's own null distribution** of the same aggregate score (split the reference immune-cell population into two random halves; use one half to compute reference mean/SD per arm, score the other half the same way as the epithelial-proxy cells, and take that held-out half's 99th percentile as the threshold) — not an arbitrarily chosen cutoff. A cell scoring above this threshold is called `CNV_HIGH` (malignancy-consistent); at or below is `CNV_LOW` (not malignancy-confirmed by this method — could be normal/reactive epithelium, or a real tumor cell this coarse method fails to flag).
6. **Primary Module B output**: CEACAM5-positive fraction recomputed within `CNV_HIGH` epithelial-proxy cells only, per patient/specimen, for the 3 treated patients (`indication_id=mcrc_preop_chemotherapy_crlm`). The `CNV_LOW` epithelial-proxy subset's CEACAM5 rate is also reported, for transparency, not as the headline number.

## Explicit limitations (locked before running)

- Arm-level, not gene-window-level — cannot detect focal CNV events smaller than an arm; a real malignant cell with only focal alterations could be missed (false `CNV_LOW`).
- ~75% gene-to-arm coverage; the missing 25% (often less-characterized loci) contributes no signal.
- Reference is tumor-site immune cells, not the paper's own reference population (not disclosed in the Methods excerpt available to this analysis) — a different, defensible, but not identical choice.
- This does not reproduce the paper's own reported CNV calls; it is an independent, coarser approximation of the same general strategy (expression-based CNV inference vs. an immune-cell reference), not a validation of the paper's exact numbers.
- Still `evidence_directness=UNCALIBRATED_PROXY`, not `DIRECT` — an arm-level expression-based CNV score is not a genomic (DNA-level) CNV call, and is itself an indirect readout of malignancy, not malignancy itself.

## Interpretation, staying honest about what this method can and cannot show

- **What this coarse method is missing, relative to real InferCNV-style workflows**: canonical InferCNV smooths *within* each cell, along genes in genomic order, using a moving window across adjacent genes per chromosome, then centers/subtracts against the reference before scoring. This method has none of that — no gene-order local structure (arm bucketing discards gene order entirely), no moving-window smoothing, and no explicit centering/reference-subtraction step (the z-score/`z^2` aggregation here is a coarser stand-in). Optional cross-cell subclustering or an HMM state model is a downstream refinement in the canonical pipeline, not the primary source of its resolving power; an earlier version of this document cited "no cross-cell smoothing" as the main reason for this method's underpowering, which overstated that step's role and understated the missing within-cell gene-order structure — corrected here per PR #75 round-1 review. The arm-level `mean(z^2)` aggregate is also a magnitude-only score: it erases the sign of the shift, so it cannot distinguish an arm-level gain from a loss — a real added limitation beyond coarser resolution alone.
- **Lineage confounding is an equally plausible, not a secondary, explanation for the median shift.** Epithelial and immune cells are different lineages with genuinely different transcriptional programs (crypt-villus axis, secretory vs. absorptive differentiation, etc.), and arm-level averaging does not fully control for lineage-driven expression-breadth differences unrelated to copy number. This method cannot distinguish "real CNV signal" from "lineage-driven expression variance" as the source of the median shift, especially without a matched-lineage (e.g., normal colonic epithelium) reference, which is not available in this dataset. Insufficient CNV resolution (the point above) and lineage confounding are **co-equal, parallel, un-excluded explanations** for the observed shift — neither is favored as more likely than the other by anything in this analysis.
- **Conclusion: this attempt does not confirm malignancy at the single-cell level for `GSE178318`'s treated-cohort epithelial-proxy cells, and does not produce a reliable CNV-confirmed CEACAM5 prevalence number.** A 2.02x threshold-exceedance enrichment and a ~2.1x median shift are real, but still consistent with a substantially-overlapping-distributions, mostly-not-separable population. The result is best described as an **observed CNV-like score shift with an ambiguous, nonconfirmatory signal** — not "real CNV-score elevation" and not simply "underpowered," both of which state more certainty than this analysis supports about what is actually driving the shift. `TE004`/`TE005` (the epithelial-proxy screen, explicitly not malignancy-confirmed) remain Module B's primary evidence for `tgt_ceacam5`. This CNV-lite attempt is recorded as a distinct, honestly-characterized piece of evidence, not folded into or presented as strengthening the epithelial-proxy numbers.
- Module B's actual malignant-cell prevalence question for `tgt_ceacam5` **remains open** — now for a more specific, characterized reason (this coarse method's signal is ambiguous and cannot be confidently attributed to CNV vs. lineage vs. resolution loss) rather than "not attempted."
