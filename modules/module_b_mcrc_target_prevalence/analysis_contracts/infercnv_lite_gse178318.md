# Module B — CNV-based malignancy confirmation for `GSE178318` epithelial-proxy cells

Written before running (per `modules/README.md`'s working-structure convention), locking the method and reference-population choice so they aren't picked after seeing the result. This is the follow-up to `tgt_ceacam5.md`'s epithelial-proxy screen, per web-ChatGPT's PR #74 round-2 guidance: the epithelial-proxy screen alone does not confirm malignancy; `GSE178318`'s own publication confirms it via InferCNV.

## What this is and is not

This is a **chromosome-arm-level relative expression score**, not a reproduction of the source publication's fine-grained, per-gene-windowed InferCNV. It is a real, methodologically standard simplification (arm-level or chromosome-level aggregate CNV scoring is used in multiple published CNV-inference workflows as a lighter-weight alternative to full gene-window smoothing), not an ad hoc substitute — but it has materially coarser resolution than the paper's own method and will not detect focal (sub-arm) copy-number events. Stated explicitly everywhere this result is used.

## Method (locked before running)

1. **Gene → chromosome-arm mapping**: `DATA/1.Databases/HGNC_gene_id_mapping/raw/hgnc_custom_download.tsv` (already-fetched, local; `Ensembl gene ID` + `Chromosome` columns), joined against `GSE178318_genes.tsv.gz`'s Ensembl IDs. Chromosome-arm parsed via `^(\d{1,2}|X|Y)([pq])` from HGNC's cytogenetic-band string (e.g. `17p13.3` → `17p`); rows that don't match this pattern (withdrawn/reserved HGNC entries, unplaced/centromeric genes, mitochondrial genes) are excluded from arm scoring. Coverage: 25,390 of 33,694 (75.4%) of `GSE178318`'s genes resolve to a chromosome arm. An arm bucket is only used if it has >=10 resolved genes (avoids single-gene-driven noise).
2. **Reference/normal population**: QC-passing cells classified `immune` (per `scripts/annotate_gse178318_cell_types.py`'s existing classification) **within `PRIMARY_CRC`/`LIVER_METASTASIS` samples only** — not `PBMC` samples. `PBMC` cells go through a different collection/processing pipeline (blood draw vs. tissue dissociation) than tumor-site samples; using them as the CNV reference risks a technical batch artifact being read as a CNV signal. Tumor-site immune cells share the same dissociation/library-prep pipeline as the epithelial-proxy cells being scored, which is the more standard and defensible reference choice.
3. **Per-cell arm signal**: for each cell, per arm, `log1p(arm_raw_count_sum / total_UMI * 10000)` (CP10K-style per-cell library-size normalization, same spirit as the existing marker-score normalization). Reference mean and SD per arm are computed from the reference population defined in (2).
4. **Per-cell CNV score**: for each epithelial-proxy cell (QC-passing, classified `epithelial` in `PRIMARY_CRC`/`LIVER_METASTASIS` samples), per-arm z-score against the reference mean/SD, then an aggregate score = mean of `z^2` across all usable arms (a chi-square-like aggregate, not a simple sum, so the score isn't just proportional to the number of arms).
5. **CNV-high / malignancy-consistent threshold**: computed from the **reference population's own null distribution** of the same aggregate score (split the reference immune-cell population into two random halves; use one half to compute reference mean/SD per arm, score the other half the same way as the epithelial-proxy cells, and take that held-out half's 99th percentile as the threshold) — not an arbitrarily chosen cutoff. A cell scoring above this threshold is called `CNV_HIGH` (malignancy-consistent); at or below is `CNV_LOW` (not malignancy-confirmed by this method — could be normal/reactive epithelium, or a real tumor cell this coarse method fails to flag).
6. **Primary Module B output**: CEACAM5-positive fraction recomputed within `CNV_HIGH` epithelial-proxy cells only, per patient/specimen, for the 3 treated patients (`indication_id=mcrc_preop_chemotherapy_crlm`). The `CNV_LOW` epithelial-proxy subset's CEACAM5 rate is also reported, for transparency, not as the headline number.

## Explicit limitations (locked before running)

- Arm-level, not gene-window-level — cannot detect focal CNV events smaller than an arm; a real malignant cell with only focal alterations could be missed (false `CNV_LOW`).
- ~75% gene-to-arm coverage; the missing 25% (often less-characterized loci) contributes no signal.
- Reference is tumor-site immune cells, not the paper's own reference population (not disclosed in the Methods excerpt available to this analysis) — a different, defensible, but not identical choice.
- This does not reproduce the paper's own reported CNV calls; it is an independent, coarser approximation of the same general strategy (expression-based CNV inference vs. an immune-cell reference), not a validation of the paper's exact numbers.
- Still `evidence_directness=UNCALIBRATED_PROXY`, not `DIRECT` — an arm-level expression-based CNV score is not a genomic (DNA-level) CNV call, and is itself an indirect readout of malignancy, not malignancy itself.

## Results (2026-08-23)

Run via `python3 scripts/infercnv_lite_gse178318.py --gene CEACAM5`, 111s. Full table: `results/tgt_ceacam5_cnv_confirmed_prevalence.tsv` (gitignored, not committed — regenerable).

- Reference population (QC-passing, `immune`-classified cells in `PRIMARY_CRC`/`LIVER_METASTASIS` samples, excluding `PBMC`): **76,562 cells**, split into a fit half and a held-out half.
- `CNV_HIGH` threshold, set from the held-out reference half's own 99th percentile: **10.41**.
- **Epithelial-proxy cells scored: 9,973.** Score distribution: min 0.27, p10 0.72, p25 1.12, **median 1.48**, p75 1.80, p90 2.32, p99 14.22, max 49.55.
- **Reference (fit-half) score distribution for comparison**: median 0.68, p90 1.30, p99 10.41 (= the threshold, by construction).

**The finding, stated honestly**: epithelial-proxy cells show a real, modest upward shift in median CNV score versus the tumor-site-immune reference (1.48 vs 0.68, roughly 2.2x) — directionally consistent with the presence of malignant signal. But the two distributions **overlap substantially**; only the top ~1% of epithelial-proxy cells (by construction, matching the reference's own 99th-percentile definition) clear the pre-registered `CNV_HIGH` threshold. Per-sample `CNV_HIGH` cell counts are almost all very small: 0-34 cells per sample (several samples have 0-2), which is **too few to support a reliable per-sample CEACAM5-positive-fraction estimate** — that fraction with a denominator of 1-9 cells is noise, not signal, exactly the kind of small-n instability this project's own discipline (Module B's "Cannot prove": n is descriptive, not population prevalence) already warns against at even the patient level, let alone the single-cell level here.

## Interpretation, staying honest about what this method can and cannot show

- **This arm-level, single-cell, no-cross-cell-smoothing method is underpowered for confident single-cell malignancy calls at a statistically principled threshold.** Real InferCNV-style workflows typically cluster similar cells before scoring and/or apply additional cross-cell smoothing, which substantially boosts the effective signal-to-noise ratio versus scoring each cell independently, as this method does. That difference in design, not necessarily an absence of malignant signal in the data, is a plausible explanation for why so few cells individually clear a 99th-percentile bar even though the population-level median is real and directionally consistent with malignancy.
- **An alternative, equally plausible explanation for the median shift**: epithelial and immune cells are different lineages with genuinely different transcriptional programs (crypt-villus axis, secretory vs. absorptive differentiation, etc.), and arm-level averaging does not fully control for lineage-driven expression-breadth differences unrelated to copy number. This method cannot distinguish "real CNV signal" from "lineage-driven expression variance" as the source of the median shift — a real, stated limitation of expression-based CNV inference across different cell lineages, especially without a matched-lineage (e.g., normal colonic epithelium) reference, which is not available in this dataset.
- **Conclusion: this attempt does not confirm malignancy at the single-cell level for `GSE178318`'s epithelial-proxy cells, and does not produce a reliable CNV-confirmed CEACAM5 prevalence number.** `TE004`/`TE005` (the epithelial-proxy screen, explicitly not malignancy-confirmed) remain Module B's primary evidence for `tgt_ceacam5`. This CNV-lite attempt is recorded as a distinct, honestly-characterized piece of evidence (its real finding — a modest, ambiguous, directionally-consistent-but-not-confirmatory median shift — and its real limitation — underpowered at the single-cell level), not folded into or presented as strengthening the epithelial-proxy numbers.
- Module B's actual malignant-cell prevalence question for `tgt_ceacam5` **remains open** — now for a more specific, characterized reason (this coarse single-cell method is underpowered) rather than "not attempted."
