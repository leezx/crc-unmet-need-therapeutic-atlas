No additional QC filtering is applied here.

## Method

1. Restrict to cells whose `cluster` value starts with `Tu` (author-defined tumor cells) — **not** an EPCAM-only proxy. This is a materially stronger starting point than `GSE178318`'s screen (see that dataset's own `analysis_contracts/tgt_ceacam5.md`): tumor-cell identity here is the source publication's own author-defined cluster label, not a single-gene marker score invented because no author annotation existed. This is **not** an independent malignancy validation — the original authors' own analysis code clusters cells, manually renames broad clusters (Tumorcell/Fibroblast/Endo), then re-clusters the Tumorcell subset into `Tu01`-`Tu11`; this screen reuses that labeling as deposited, it does not re-derive or independently confirm it.
2. For each target gene, stream `GSM7058755_non_immune_counts.txt.gz` (a dense 17,515-gene x 41,892-cell TSV, not `GSE178318`'s sparse Matrix Market format) to find the one row matching the gene symbol — an O(n_genes) scan, the full matrix is never materialized in memory.
3. Per patient x organ (`CC` = primary colorectal cancer, `LC` = liver metastasis; both `CCT`/`LCT` in the raw organ codes), compute the fraction of tumor cells with a nonzero raw count for the gene. Each such patient x organ group is one **stratum** — the statistical unit this screen actually reports on, not an individual cell.
4. `RNA_no`/`RNA_low`/`RNA_high` buckets, same thresholds as `GSE178318`'s screen: `RNA_no` < 5%, `RNA_low` 5-50% inclusive, `RNA_high` > 50%.
5. All five patients in this file (`s0107`/`s0115`/`s0813`/`s0920`/`s1231`) received preoperative chemotherapy and/or radiotherapy (this dataset's registry-level `treatment_annotation=CHEMOTHERAPY_AND_OR_RT_PREOPERATIVE`) — this does **not** mean every patient received the same modality or regimen, only that each received at least one of the two; no per-patient regimen is recorded here. No treated/treatment-naive split is needed, unlike `GSE178318` (whose cohort genuinely mixes treated and treatment-naive patients). Both `CC` and `LC` sites fall under `indication_id=mcrc_preop_chemotherapy_crlm` (its `anatomy` field is explicitly `PRIMARY_AND_LIVER_METASTASIS`).

## Interpretation, staying inside what this screen can prove

- **This is not a CNV-confirmed malignancy result** — `Tu0N` cluster membership is the source publication's own author-defined clustering label, cross-checked here only by cluster count (11/11 exact match) and cell-count plausibility, not independently re-derived from CNV inference, and not itself an independent malignancy validation (see Method item 1). It is a materially more direct starting point than `GSE178318`'s EPCAM-only screen, but the same `evidence_directness=UNCALIBRATED_PROXY` applies — this is still an RNA detection-fraction read, not a protein/surface-density measurement.
- **Under this assay's own predefined RNA_no/RNA_low/RNA_high heuristic** (not a calibrated cross-gene prevalence scale — the five genes differ in transcript abundance, dropout propensity, and dynamic range, the same limit PR #77 already established for `GSE178318`'s screen): `CEACAM5` reaches `RNA_high` in 5 of 10 patient x site strata (`s0107` CC, `s0115` CC, `s0813` CC and LC, `s1231` CC); `TACSTD2` in 1 of 10 (`s0115` LC, n=55, a small sample); `ERBB2`, `F3`, and `NECTIN4` never reach `RNA_high`. `F3` reaches `RNA_no` in 3 of 10 strata (`s0115` CC, `s0920` CC, `s0920` LC); `NECTIN4` in 4 of 10 (`s0107` LC, `s0115` LC, `s0920` CC, `s0920` LC); `CEACAM5` in 1 of 10 (`s0115` LC); `ERBB2` and `TACSTD2` never reach `RNA_no`. This is an assay-internal descriptive pattern only, not a cross-target prevalence ranking. The relationship to `GSE178318`'s own screen is likewise descriptive, not quantitative replication: both cohorts observe `CEACAM5` reaching `RNA_high` strata, but the two screens use different tumor-cell definitions (`GSE178318`: EPCAM-only proxy; `GSE225857`: author-defined `Tu0N` clusters), so the two cannot be compared as replicate measurements of the same quantity.
- **No target is `RNA_no` in every stratum** — every target has at least some positive detection in every patient.
- `s0920`'s tumor population (6,382 CC + 9,976 LC cells) is the largest of the five patients by a wide margin — far larger than the other four patients combined, not the smallest — and shows the lowest detection fractions among the five patients for four of the five targets (all but `TACSTD2`). This is a genuine finding, not investigated further here (could reflect real inter-patient heterogeneity, a distinct tumor subclone composition, or a batch effect; this screen cannot distinguish those explanations, and it is not attributable to low cell yield, since `s0920` has the opposite of a low yield).
- `evidence_directness=UNCALIBRATED_PROXY` for all five new `target_evidence.tsv` rows (`TE027`-`TE031`) — same measurement_layer/directness convention as `GSE178318`'s `TE004`/`TE005`, never `DIRECT` or `CALIBRATED_PROXY`.
- This is now a genuine **second, independent, treated CRLM cohort** for all five targets under `indication_id=mcrc_preop_chemotherapy_crlm`, obtained entirely through GEO's public route — no CNSA DAC application was ever filed or needed.
