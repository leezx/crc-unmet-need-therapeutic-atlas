# Module B — MCRC_TARGET_PREVALENCE

## Goal

> **mCRC 里到底有没有足够多能被 X 地址访问的癌细胞？**

## Inputs

- `GSE225857` — 6 CRLM patients, 27 matched primary/LM/adjacent/PB samples, all preoperative chemo and/or RT, scRNA + spatial.
- `GSE178318` — matched primary + CRLM scRNA, 6 patients, 3 with preoperative chemo.
- Refractory/clinical bulk datasets registered under this module in `../../DATA/registry/module_classification.tsv`.

## Per-target output

For each candidate X from Module A:

- malignant-cell detection
- X-high fraction
- patient-positive fraction
- between-patient heterogeneity
- within-patient heterogeneity
- metastatic lesion coverage

## Naming rule

Bucket output as `RNA_no / RNA_low / RNA_high`. This can **never** be upgraded to `surface-density high` — not even by a completed Module D protein calibration. Module D only provides protein-level support/concordance (whole-tissue MS ≠ malignant-cell membrane density, PDO protein ≠ tumor surface density); a real surface-density claim requires a target-specific quantitative surface assay or equivalent direct evidence, which is neither `RNA_high` nor a Module D result. Record `evidence_directness` accordingly in `../../schemas/target_evidence.tsv` (`UNCALIBRATED_PROXY` for RNA alone, `CALIBRATED_PROXY` at best once Module D protein concordance exists, never `DIRECT` from this module).

## Cannot prove

scRNA ≠ surface density. Small cohorts (n=6) are within-cohort descriptive statistics, not population prevalence claims until replicated.

Output rows `target_id`-keyed per `../../schemas/target_evidence.tsv`.

**CNV-based malignancy confirmation attempted, 2026-08-23 — ambiguous, not confirmatory.** New `../../scripts/infercnv_lite_gse178318.py` builds a chromosome-arm-level CNV score (gene-to-arm mapping from the local HGNC gene-position reference, `config/external_sources.yaml`'s `module_b_gene_position_reference` block, path resolved from that YAML and checksum-locked via `DATA/reference/hgnc_gene_id_mapping_source_lock.tsv`; 25,376 of 33,694 genes resolve to an arm, 43 arms with >=10 genes) scored against a held-out half of a tumor-site immune reference — a coarser, independently-designed approximation of the source paper's own fine-grained InferCNV, not a reproduction. Both the reference and the epithelial-proxy population are restricted to the 3 treated patients (`COL15`/`COL17`/`COL18`), matching `TE004`'s `indication_id=mcrc_preop_chemotherapy_crlm` (a pooled six-patient version — 82% treatment-naive cells — is kept only as a method diagnostic, never as the canonical statistic; an earlier round of this PR wrongly reported the pooled numbers under this treated-cohort row). Result: epithelial-proxy cells (n=1,786) show a modest median CNV-score shift vs. the held-out treated-cohort reference (n=19,002; 1.32 vs 0.63, ~2.1x), directionally consistent with malignant signal, but the distributions overlap substantially — 36/1,786 (2.02%) of epithelial-proxy cells clear the held-out reference's own 99th-percentile threshold vs. 190/19,002 (1.00%) of the held-out reference's own cells (enrichment ratio 2.02x, a modest enrichment), and per-sample counts above that threshold are mostly single-digit (0-22 cells across the 6 treated samples), too small for a reliable prevalence estimate. This coarse arm-level method is missing within-cell gene-order smoothing and a centering/reference-subtraction step relative to real InferCNV workflows (not primarily "no cross-cell smoothing"), and its aggregate score erases gain/loss direction; lineage-driven expression differences (epithelial vs immune, unrelated to copy number) are an equally plausible, co-equal explanation for the shift, not a secondary caveat — so the result is best read as an observed CNV-like score shift with an ambiguous, nonconfirmatory signal, not evidence the cells aren't malignant.
