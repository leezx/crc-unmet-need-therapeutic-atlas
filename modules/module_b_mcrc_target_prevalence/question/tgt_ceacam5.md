## Status: `GSE178318` has an epithelial-proxy answer (2026-08-23, corrected round 1 of PR #74's review) — the malignant-cell question itself is still open

See `data_lock/tgt_ceacam5.md` and `analysis_contracts/tgt_ceacam5.md` for the real, QC-filtered result: every one of `GSE178318`'s 6 patients (3 treated -- `TE004`, `indication_id=mcrc_preop_chemotherapy_crlm`; 3 treatment-naive -- `TE005`, `indication_id=mcrc_liver_metastasis`, kept as separate context evidence) has a detectable CEACAM5-positive epithelial-proxy subpopulation in both primary and liver-metastasis tissue. **This is EPCAM-based epithelial-proxy screening, not malignancy-confirmed** -- the source publication itself confirms malignancy via InferCNV, which is not reproduced here, so the question this file poses (\"...能被地址访问的恶性上皮细胞\") is not fully answered, only approximated. `GSE225857` -- this module's other `CORE_ACTIVE` dataset for this indication -- remains genuinely blocked on CNSA access; no `target_evidence.tsv` row exists for it. This mirrors the discipline this repository has used for every genuine gap since the Phase 1 verification pass (PR #71): preserve the gap, don't force a closure, and don't let a proxy result stand in for the malignancy-confirmed claim the question actually asks for.
