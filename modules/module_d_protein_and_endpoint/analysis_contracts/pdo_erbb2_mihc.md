## What's actually in `Data S3.xlsx`

`MCRC_liver_metastasis_PDO_2026` (Kryeziu, Sveen, Lothe et al. 2026, "Patient-derived organoids from metastatic colorectal cancer mirror tumor heterogeneity and predict patient survival and drug sensitivity", Mendeley Data v3, `doi:10.17632/hr94h42xdc.3`; publication PMC13293968) is a living biobank of 213 CRC liver-metastasis (CRLM) patient-derived organoids (PDOs) from 102 patients. `Data S3.xlsx` (114.6 KB, downloaded 2026-08-25, checksum-verified) is a small, **source-provided processed** multiplex-fluorescent-IHC (mIHC) table — not a raw measurement: one row per PDO x protein-marker x staining-round, with a continuous `mean_express_PDO` value (mean relative fluorescence intensity per PDO image, already normalized to total cellular content by the source authors — not a raw pixel count and not a High/Medium/Low/Not-detected category, unlike `HPA_CRC_cancer_tissue`'s IHC read).

Per the source publication's own methods text (independently fetched and confirmed 2026-08-25): "Fluorescence-based multiplex immunohistochemistry and digital image analyses were used to analyze in situ expression of fourteen proteins in 136 PDOs and two corresponding tumor tissue samples from 67 patients." The fourteen markers are `ABCB1`/`ABCG2`/`CDH1`/`CDX2`/`CFTR`/`ERBB2`/`HSF1`/`KI67`/`KRT20`/`KRT7`/`RCC2`/`RIPK1`/`TP53`/`UGT1A` — **only `ERBB2` is among this repository's five `A_CLINICAL` targets.**

**Patient count is the publication's own stated denominator (67), not independently re-derived.** Some `PDO_id` values in the raw file carry decimal suffixes (e.g. `Pt54.2`, `Pt54.3`, `Pt6.2`, `Pt22.2`) whose meaning — a distinct patient vs. a second lesion/re-resection from the same patient — is not resolved in the fetched text. Rather than guess (and risk exactly the kind of specimen-vs-patient miscount PR #82 round 1 caught for `PXD055821`), this contract uses the paper's own "136 PDOs ... from 67 patients" statement as the panel-wide denominator and does not compute a separate ERBB2-specific patient count from parsing `PDO_id` strings. PDO-level counts (below) are unambiguous and used instead.

## *** The critical caveat: `ERBB2` was excluded from this panel's own analysis — worded exactly as the source states it

The same methods paragraph states, **verbatim**: *"KRT7 and ERBB2 were excluded from analysis due to no or very low expression levels, respectively."*

**"Respectively" matters and must be preserved**: `KRT7` was excluded for **no** expression; `ERBB2` was excluded for **very low** expression — two different findings, not one shared caveat. (An earlier version of this contract collapsed both into one string, erasing that distinction — caught and fixed in PR #84 round 1 review.)

This means: the 136 per-PDO `ERBB2` values are still physically present in `Data S3.xlsx` — this script reads them, unmodified — and the source authors excluded `ERBB2` from **downstream analyses of this specific multiplex protein-expression panel** because the measured expression was very low. **This repository does not claim the reagent failed, or that these values are assay noise/background** — the source publication makes neither claim. **This repository cannot determine, from what the source publication states, whether the very-low-expression finding reflects genuinely low `ERBB2` protein abundance in these PDOs, limited sensitivity/performance of this specific multiplex assay configuration (polyclonal antibody, catalog `A0485`), or both** — and does not resolve that ambiguity by guessing in either direction. This is, if anything, a more informative framing than "reagent failure" would have been: it leaves open the real possibility that this is a genuine `ERBB2`-low protein-layer signal, potentially directionally compatible with this target's RNA/HPA evidence — while still refusing to treat it as calibrated, confirmatory evidence.

One piece of context from elsewhere in the same publication, reported without over-interpreting it: a *different* `ERBB2` antibody clone (single-plex DAB IHC, clone `CB11`) was used successfully for a case-report figure (patient `Pt137`, Figure 7A, later found to be `ERBB2`-amplified with heterogeneous expression across lesions) — "Immunohistochemistry stains show in situ ERBB2 expression in the primary tumor, two CRLMs, and the corresponding PDOs." That one patient's successful single-plex stain does **not** establish that the cohort-wide multiplex signal is a reagent artifact rather than real low expression, an assay-sensitivity limit, or some mix of both — this repository does not draw that inference. It is reported here only as a fact about the publication, not as evidence resolving the ambiguity above.

`ERBB2` was excluded only from analyses **of this specific multiplex panel** — the same publication goes on to analyze `ERBB2` amplification, single-plex `ERBB2` IHC, and anti-`ERBB2` treatment response elsewhere (the `Pt137` case report). Calling it "excluded from every downstream analysis in their own paper" would overclaim; this contract does not.

**Every use of this evidence row must carry this caveat, worded this precisely.** It is not presented as clean corroborating evidence alongside `PXD055821`'s MS read (`TE033`) or `HPA_CRC_cancer_tissue`'s IHC read (`TE038`) — it is a third, independent protein-layer measurement type, but one the source publication's own analysis excluded, for a reason this repository cannot adjudicate.

## Method

1. `scripts/extract_pdo_erbb2_mihc.py --gene ERBB2` opens `Data S3.xlsx`, filters to `Prot_marker == "ERBB2"` rows, and computes: number of rows with a positive numeric `mean_express_PDO` value, the fraction of rows that are nonzero, and median/min/max of the nonzero values. **This is a `summarize_values()` function, not a "detection" function** — the source publication states no assay-detection threshold, so a nonzero value is not treated as evidence of biological detection; the script and this contract never claim "detected in N/136."
2. Checksum-verified against `DATA/registry/MCRC_liver_metastasis_PDO_2026/file_inventory.tsv` before use — fails closed on missing file or checksum mismatch.
3. The script refuses (fails closed) any `--gene` not among the panel's fourteen markers, rather than silently returning zero rows.

## Interpretation, staying inside what this screen can prove — and cannot

- **This is not clean corroborating evidence, and it is also not evidence of assay failure.** Read alongside `PXD055821`'s MS read (93.3% specimen with nonzero intensity, `TE033`) and `HPA_CRC_cancer_tissue`'s IHC read (mostly `Not detected`, 6/11 patients, `TE038`), the honest reading of a third source with a positive numeric value in every PDO is: **the source publication's own analysis of this panel found `ERBB2` expression too low to trust, and this repository cannot determine whether that reflects true low `ERBB2` protein abundance, an assay-sensitivity limit specific to this multiplex configuration, or both.** No directional conclusion is drawn from this row — it is reported for completeness, with its caveat, not folded into a combined protein-layer verdict.
- **PDO-level, not primary-tissue-level.** PDOs are cultured organoids derived from resected CRLM tissue, not the tissue itself — an additional layer of biological distance from any of this repository's other Module D sources (which read primary tumor tissue directly).
- `evidence_level=EXPLORATORY_UNDERPOWERED` and `confidence=LOW` (rather than `SCREENING_LEVEL`/`MEDIUM` like `TE033`/`TE038`) specifically because of the source publication's own exclusion of this marker from this panel — a different kind of weakness than small-n underpowering (source-excluded, cause ambiguous between biology and assay sensitivity, not simply small n), but the closest available vocabulary term in this schema, chosen to signal maximum skepticism; the actual reason is always stated in the claim/notes text, never left to the tier alone to convey.
- `evidence_directness=UNCALIBRATED_PROXY` — unchanged either way by this caveat: mIHC (trusted by the source authors or not) is still not membrane-specific, quantitative antigen density, or a calibrated surface assay. Per this repository's Module D contract (`modules/module_d_protein_and_endpoint/README.md`), this does NOT establish surface density even setting the exclusion caveat aside.
- `indication_id=mcrc_liver_metastasis` (anatomy-only, `ANY` treatment_line/prior_therapy) — chosen because the source publication describes this living biobank as patient-derived organoids from resected CRC liver metastases, matching `PXD055821`'s anatomy-only mapping; no treatment-status claim is made.
