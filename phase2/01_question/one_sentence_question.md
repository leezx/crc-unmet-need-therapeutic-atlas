# Phase 2 — one-sentence question

## Central question

在 advanced/metastatic CRC，尤其 colorectal liver metastasis（CRLM）中，是否存在跨患者可复现的恶性上皮可塑性状态，能够同时满足：

1. 在转移或治疗相关样本中富集；
2. 包含可药物化或 ADC-compatible 的细胞表面靶点；
3. 在正常组织中具有可接受的表达窗口；
4. 获得独立功能依赖、药物敏感性或 perturbation evidence 支持。

## Falsifiable hypothesis

一个 metastasis-enriched、fetal/plasticity-like malignant epithelial program 会在独立 CRLM 单细胞队列中复现，并产生至少一个同时通过 surface accessibility、normal-tissue exclusion 和 functional vulnerability 门禁的候选靶点。

## Primary outcome

不是“列出高表达基因”，而是形成一个带证据等级的 target dossier：

`malignant-state enrichment → cross-cohort replication → surface accessibility → normal-tissue window → functional support → clinical indication fit`

## Kill criteria

- 状态只反映 cell cycle、stress 或低质量，而不是恶性上皮状态；
- 在独立 CRLM 队列中无法复现；
- 候选靶点没有细胞表面证据或正常组织窗口；
- 功能依赖只来自单一模型或无法区分表达相关与因果脆弱性；
- 结果仅重复既有 plasticity atlas，不能增加 therapeutic decision value。

## Scope boundary

Phase 2 允许下载和分析经过 data-lock 的公开数据，但不会在没有分析契约、QC 和独立 PR 审核前生成 `APPROVED` target 或临床治疗建议。
