# Registry

`datasets.tsv` is the canonical Phase 1 candidate index. `UNKNOWN` is expected until the original paper and repository are inspected. `P0_DOWNLOAD` is a proposed priority, not permission to download. New entries remain `CANDIDATE` until source, file-level availability, license, and clinical-context checks are reviewed.

Each approved dataset gets a directory containing a README and source manifest. Do not place raw or processed biological files here.
